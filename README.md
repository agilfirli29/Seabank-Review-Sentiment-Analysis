# SeaBank Review Sentiment Analysis

An interactive dashboard for exploring sentiment analysis results from 5,000 SeaBank application reviews.

## Overview

This project visualizes user sentiment and review patterns to provide insights into user perceptions of the SeaBank application.

The dashboard includes:

- Sentiment distribution
- Rating distribution
- Daily sentiment trends
- Positive and negative word clouds
- Most frequently occurring words
- Interactive review data filtering

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Matplotlib
- WordCloud

## Dataset

The dataset contains 5,000 user reviews of the SeaBank application, including review text, rating, date, and sentiment classification.
